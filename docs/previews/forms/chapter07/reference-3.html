휴직자 기여금납부 안내

□ 휴직자 당월기여금 납부 여부

○ 본인이 납부를 원하는 경우: 매월 당월기여금 개별 납부

○ 납부를 원하지 않은 경우: 복직하여 매월 당월기여금과 같은 금액의 소급기여금 납부

○ 휴직자가 발생한 경우 휴직중에도 기여금을 납부할 수 있음을 반드시 안내

※ 육아휴직수당을 수령한 공무원이 기여금납부를 원할 경우 매월 급여에서 기여금 공제

□ 현재 휴직 중인 자

○ 지금으로부터 향후의 휴직기간에 대하여만 기여금을 납부할 수 있고, 이미 지나간 휴직기간에 대하여는 복직하여 소급기여금 납부

□ 기여금 개별납부 방법

○ 인터넷 뱅킹: 공단 기여금납부계좌에 인터넷뱅킹을 통하여 기여금 개별 납부

○ 무통장 입금: 은행을 방문하여 공단 기여금납부계좌에 무통장 입금

※ 기여금납부계좌 및 입금방법: 공단누리집 → 서식자료실 → 연금서식 → 기여금납부서 (개인용) 참조

□ 매월 납부할 기여금액

○ 본인에 대한 당월기여금은 공단누리집 → 내연금보기 → 재직자정보 → 현재 기여금액에서 확인 가능

□ 휴직자가 복직한 경우 소급기여금 징수

○ 공단누리집 → 연금담당자 → 징수관리 → 재직자관리 → 입휴/감축관리 → 개인별 감축기간 조회에서 소급기여금 납부기간 조회, 기관 급여시스템 소급기여금 납부기간에 반영

□ 유의사항

○ 휴직자의 경우에 일부 미납기여금을 추징하게 되면 공단전산에서 휴직자가 당월기여금을 납부하는 자로 인식하여 당월기여금 1개월분을 미납으로 표시되므로 미납기여금 추징시주의 요망

- 휴직자 미납기여금 징수 시에는 당월기여금과 함께 징수하여야 미납기여금이 발생하지 않음

○ 기여금 징수율이 2020년도 9%를 납부하도록 하고 있고, 매년 기준소득월액 기준이 올라가므로 휴직중이라도 기여금을 납부하는 것이 유리하다고 볼 수 있음
