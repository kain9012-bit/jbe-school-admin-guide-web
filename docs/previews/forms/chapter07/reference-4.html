기준소득월액 적용 안내

□ 기준소득월액의 적용기간

○ 기준소득월액은 해당 연도 5월부터 다음 연도 4월까지 적용

□ 신규임용자의 기준소득월액 적용

○ 해당 직급 호봉이 기여금 조견표에 없는 경우

- 예상소득금액 내역서를 공단에 제출 기준소득월액 확인

- 공단누리집 → 민원상담 → 각종서식 → 연금서식 → 예상소득금액 입력양식

□ 전입자의 기준소득월액 확인

○ 연금업무지원시스템 → 징수관리 → 기준소득관리 → 전출입 기준소득월액 내려받기

□ 휴직기간 등의 기준소득월액

○ 휴직기간 또는 시간제근무기간 중의 기준소득월액은 휴직일 전날 또는 시간제근무기간이 시작되기 전날의 기준소득월액에 매년 5월 1일에 공무원보수인상률을 곱하여 산정한 금액

□ 기준소득월액 이의신청

○ 호봉정정 등으로 기준소득이 변경된 경우에 이의신청서 제출(봉급자료 첨부)

- 공단누리집 → 민원상담 → 각종서식 → 연금서식 → 기준(개인)소득자료 이의신청서
