# 전북 학교행정업무 길라잡이 웹판

전북특별자치도교육청 「학교행정업무 길라잡이」를 업무 흐름과 검색 중심의
웹 문서로 제공하기 위한 시범 프로젝트입니다.

## 제1편 시범판

- 제1편 행정업무 및 보안 매뉴얼 37쪽
- 9개 업무 처리 흐름
- FAQ 55건
- 서식·예시 19종
- 업무·질문·서식 통합 검색
- 원문 PDF·HWP·HWPX 내려받기
- 모바일 반응형 화면과 키보드 접근

## 진행 원칙

- 원본 문서를 정본으로 유지합니다.
- 웹에서 재구성한 모든 내용은 원본 위치와 연결합니다.
- 검색 결과에는 자료 유형과 관련 업무를 표시합니다.
- 원문과 변환 결과를 사람이 대조 검수합니다.
- 실제 업무 처리 전 원문과 최신 법령·지침을 함께 확인하도록 안내합니다.

## 프로젝트 구성

- `docs/`: GitHub Pages에 게시할 완성 사이트
- `source/chapter-01/original/`: 교육청 원본 자료
- `scripts/`: 원문 추출, 검색 데이터 생성, 검증 도구
- `STATUS.md`: 구현 완료 항목과 공개 전 남은 작업
